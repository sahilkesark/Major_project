📌 Problem Statement

The Challenge

  • Rising health issues: India has 101M+ diabetics and 315M+ with hypertension, largely linked to poor dietary habits.
  • No easy calorie tracking: People eat without knowing nutritional value — manual calorie counting is tedious and inaccurate.
  • Generic diet plans: Existing apps provide one-size-fits-all meal plans, not personalized to Indian food or individual goals.
  • Portion estimation gap: No consumer tool accurately estimates food quantity from a photo — plate/bowl volume is critical but ignored.

Our Solution

NutriSight Pro uses AI-powered image recognition to instantly analyze food photos — detecting each item, estimating portion sizes using plate/bowl volume analysis, calculating per-item and total nutrition, and generating personalized meal plans.

Key Objectives

  • Build an AI system that identifies multiple food items in a single image
  • Estimate portion sizes using container volume analysis (plate diameter, depth, fill %)
  • Provide per-item AND total nutrition breakdown (calories, protein, carbs, fat, fiber)
  • Generate personalized meal plans based on user goals and diet preferences
  • Track daily nutrition intake with visual analytics and progress tracking

🧠 Core Feature 1: AI Food Analysis

How It Works

  1. Image Upload: User uploads or captures a food photo (drag-and-drop supported)
  2. Base64 Encoding: Image is converted to base64 and sent to Gemini Vision API
  3. AI Processing: Gemini analyzes the image using a carefully engineered prompt
  4. Structured Response: AI returns JSON with per-item nutrition, volume estimation, and health score
  5. Display & Save: Results are rendered with interactive cards and can be logged to the database

Multi-Food Item Detection

When an image contains multiple food items (e.g., a plate with rice, dal, and salad), the AI detects and analyzes each item individually — providing separate nutrition data for each, plus the combined total.

📐 Core Feature 2: Volume & Portion Estimation

Assessor's Key Question: "How are you estimating the volume of the plate or bowl? That matters the most for nutrition estimation."

Our Approach: Visual Reference-Based Estimation

The AI uses a multi-step approach to estimate food portions:

Step 1: Container Detection

  • Identify container type (plate, bowl, cup, tray)
  • Standard plate ≈ 26cm diameter
  • Side plate ≈ 20cm
  • Soup bowl ≈ 16cm, 8cm depth

Step 2: Reference Objects

  • Fork/spoon length ≈ 19cm
  • Hand width ≈ 8-10cm
  • Standard packaging sizes
  • Table edge proportions

Step 3: Volume Calculation

  • Estimate food height/depth on plate
  • Calculate fill percentage (0-100%)
  • Use food density to convert volume → weight
  • Rice density ≈ 0.9g/cm³, curry ≈ 1.0g/cm³

Step 4: Weight → Nutrition

  • Map estimated grams to per-100g nutrition data
  • Apply cooking method adjustments
  • Cross-reference with standard food databases
  • Report confidence score (0-100%)

UI Display

The app shows a dedicated "Portion Estimation Method" card that explains:

  • Methodology: Human-readable explanation of how the AI estimated portions
  • Container type & dimensions: Plate diameter, bowl depth
  • Fill percentage: How full the container is
  • Reference objects used: What the AI used for scale calibration

Security: Row Level Security (RLS)

Every table has RLS enabled. Users can only read, write, and delete their own data. This is enforced at the database level — even if the API is compromised, data isolation is guaranteed. 
  -- Example RLS policy
  CREATE POLICY "Users can view own meals"
    ON public.meals FOR SELECT
    USING (auth.uid() = user_id);

Auto-Profile Creation Trigger

When a user signs up, a PostgreSQL trigger automatically creates their profile row — no extra API call needed.
